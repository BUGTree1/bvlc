# Better VLC

Is a simple C++ ffmpeg video player

## Dependencies

[VLC SDK](https://download.videolan.org/pub/videolan/vlc)
[BuildIt](https://github.com/BUGTree1/JustBuildIt)

## Quick Start

```console
$ make
$ ./bin/bvlc
```
